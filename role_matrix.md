# Матрица ролей — учебный сервис заявок, интерфейс 1.5.0

Источник: SPEC-1.0, data/operator_observations.md. Все данные синтетические.

## Целевые роли руководства

### Оператор (operator_a / operator_b)

| Действие | Разрешено | Ограничение и как проверить |
|---|---|---|
| Создать заявку | Да, кнопка «Создать» на экране «Заявки» | Тема 1–120 символов, Описание 1–2000 символов после удаления пробелов по краям. При отказе валидации введённый текст остаётся в форме |
| Прочитать свои заявки | Да, фильтр «Мои» | Видит только собственные заявки |
| Открыть свою заявку по номеру | Да, ссылка «Открыть» или строка списка | Номер вида LAB-104 — единственный способ найти конкретную запись |
| Редактировать свою открытую заявку | Да | Только пока статус open. Чужие и закрытые заявки — нет |
| Читать чужую заявку | **Нет** | Показывается «Нет доступа к этой заявке» и ссылка «К списку» |
| Удалить заявку | **Нет** | Кнопки удаления нет |

### Техник (technician_a)

| Действие | Разрешено | Ограничение и как проверить |
|---|---|---|
| Видеть назначенные заявки | Да, фильтр «Назначенные» | Видит только назначенные ему заявки |
| Перевести заявку в работу | Да, кнопка «В работу» | Статус open → in_progress |
| Завершить заявку | Да, кнопка «Отметить выполненной» | Обязателен непустой комментарий; статус → resolved |
| Удалить заявку | **Нет** | Кнопки удаления нет |
| Читать неназначенные заявки | **Нет** | Доступ ограничивается сервером |

## Роли вне руководства (для полноты матрицы)

| Роль | Действия | Ограничения |
|---|---|---|
| manager_a | Читает все заявки, назначает исполнителя | Не может незаметно менять автора или историю действий |
| Неавторизованный пользователь | — | Не читает и не создаёт заявки |

## Общие правила, важные для руководства

- Доступ ограничивается **сервером**; отсутствие кнопки само по себе не является проверкой полномочий.
- Список и карточка показывают одни и те же значения.
- Допустимые статусы: open, in_progress, resolved. Переход в resolved требует непустого комментария исполнителя.
- Административные действия (назначение исполнителя, развёртывание, миграции) в руководство оператора не входят — только обращение в поддержку.
